# Catálogo V11

24 implementações procedurais originais criadas a partir da análise visual das prévias públicas em https://sundayscreens.com/worship-backgrounds . Nenhum vídeo, imagem, código ou arquivo do catálogo externo é incorporado na DLL. Não são cópias exatas dos loops. Céu, água e atmosfera são interpretações abstratas; não reproduzem filmagens fotorealistas.

Nomes normalizados: Warn → Warm; Subset → Sunset Gradients; Unending → Unending Grace; Warm Glow Gradiets → Warm Glow Gradient.

As cores são controladas pelo Tint e Colorize da V10. Portanto, a cor da referência externa não é uma cor fixa deste motor. Mode Off produz a base neutra conforme Tint; Color e Palette aplicam as cores escolhidas.
