# Souz Content BG — V16 unificada

Contém as 32 engines da V14-Engines, as 16 paletas prontas e o painel organizado da V15.

Em Cores, clique em Paletas para aplicar uma combinação. Personalizar abre Black To e White To no mesmo espaço. Trocar de aba não altera o BG.

Este ZIP é o projeto completo de código-fonte, não uma DLL compilada. Substitua o projeto inteiro na compilação, incluindo arquivos ocultos .github. Use o workflow Windows incluído ou siga README.md.

A identidade ABGE e os canais de parâmetros foram preservados. Alguns slots de engine receberam novos visuais na V14-Engines: mantenha backup e confira composições existentes.
