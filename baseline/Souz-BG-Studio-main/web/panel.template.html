Conectar na mesma rede

Abra o painel pelo plugin para obter o link desta instância.

Leia o QR com a câmera do tablet e toque em Conectar. Use a mesma rede Wi-Fi.

Código de uso único, válido por 5 minutos. Gere um novo para cada aparelho.

  1. Copie o endereço no computador, abra no tablet e digite o código de seis números exibido no computador. Só o IP, sem a porta, não basta.
  2. Use a mesma rede do computador. Não use 127.0.0.1 nem localhost no tablet.
  3. Se a página nem abre, permita o Resolume no firewall da rede privada. Redes de convidados podem bloquear a comunicação entre aparelhos.
  4. Se a página abre mas os controles não conectam, gere um novo código. Se só o preview falha, verifique o suporte a WebGL 2.

Escolha o IP da placa usada nessa rede. VPNs podem aparecer na lista. O IP público da internet não substitui este endereço. A porta pode mudar quando a instância é recriada.
